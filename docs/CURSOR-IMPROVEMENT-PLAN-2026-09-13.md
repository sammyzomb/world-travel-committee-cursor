# Cursor 第一階段改善交接
日期：2026-09-13

## 使用方式與範圍

這是使用者確認的改善需求文件，不代表程式已完成修正。請先閱讀目前專案規範及最新程式，核對已有改動後直接實作尚未完成的項目。保留既有成果，不重建專案，不覆蓋其他未提交變更。若與使用者之後的明確指示衝突，以較新的指示為準。

完成後 commit 並 push 到目前 GitHub 專案；本階段不部署正式網站。

## 一、題庫品質

- 將每題展開為可獨立維護的資料，增加固定 id、知識點 conceptId、適用年級、資料來源與審核狀態。
- 審核狀態至少包括：待審核、已通過、停用。正式遊戲只抽已通過題目，既有題目不得直接全部標為已通過。
- 核對題幹、每個選項、正確答案、解析及圖片是否一致，且只有一個有效答案。來源須真實支持答案，不可捏造。
- 首都、跨國領土、世界之最等題目須補足定義；無法確認者先停用。不要把法律定義與一般地理慣例混成簡單對錯。
- 先備妥足以支援完整十八級且同局知識點不重複的已審核題庫，再逐步擴充到一萬題。總數足夠之外，各年級可用題數也必須足夠。

## 二、抽題與年級規則

- 同一局不可重複 id 或 conceptId；同一知識點换問法也視為重複。
- 優先避開近期玩過的題目。必要時可放寬跨局避題，但不可放寬同局去重，也不可因此題數不足或誤判破關。
- 每級五題，答對三題通過。
- 小一最前面三題固定為簡單是非送分題，不得與後兩題混排。
- 選擇題選項數：小一～小三二選一、小四～小六三選一、國中以上四選一。是非題始終為是／否。
- 固定十八級：小一～小六、國一～國三、高一～高三、大一～大四、研一～研二。
- 只有通過研二才算完整破關；不延伸研三等關卡，題庫不足不得算破關。
- 每級完成皆有可由玩家自行繼續的休息／獎勵畫面，不強制倒數。
- 只有小六、國三、高三、大四、研二通過才顯示對應學制畢業動畫；其他年級顯示完成該年級學業。若使用人物，年齡須符合學制。
- 整局三次機會，不因升級補滿。本輪不新增補命、難度模式或無限挑戰。
- 難度按理解與判斷逐步提升，不僅以冷僻程度或資料排列順序分類。

## 三、排行榜與保存

- 檢查實際部署平台，使用該平台可運作的持久資料庫，不以示範名單或瀏覽器儲存取代全站排行榜。
- 伺服器依場次與答題紀錄核算分數及資格，不信任瀏覽器自行提交的總分或完成狀態。
- 加入場次識別、重複提交防護及基本請求頻率限制。
- 只有符合前十名資格者才能留名；排行榜不得定期重置。明确定義同分排序與重複提交的處理方式。
- 若欠缺資料庫帳號或環境變數，先完成可完成的程式及設定說明，列出需要使用者提供的項目；不可宣稱已連線成功。
- 不刪除既有正式成績，不直接執行破壞性資料遷移。先保存歷史紀錄，再處理前十名顯示。

## 四、圖片與地圖

- 保留有效地標照片與來源標示。
- 圖片標籤、說明、替代文字及其他答題前畫面文字不能直接透露答案；同時保留合理的無障礙描述。
- 尚無真實地圖點選功能的模式改名為「洲別挑戰」，不稱為地圖點選。
- 本輪不增加新的圖片、地圖或娛樂模式；保留現有有效功能，先完成品質修正。

## 五、驗證與交付

請實際檢查並回報結果，不只回報編譯成功：

- 完整十八級流程、每級五題、小一前三題順序、各級選項數、研二破關。
- 同局 id 與 conceptId 去重；多次重新開始、年級題庫不足與跨局避題回退。
- 三次機會耗盡及未達通過條件。
- 每級休息畫面與五個學制畢業節點。
- 排行榜持久保存、資格判定、分數竄改、提交失敗與重複提交。
- 手機、平板、電腦基本答題操作及圖片載入失敗處理。

交付摘要須分開列出：已完成、驗證結果、未完成、需要使用者設定的項目，以及 commit。不得把尚未完成的題庫審核或資料庫設定描述成已完成。

## 後續階段（本輪不實作）

真實互動地圖、補命模式、講座精準推薦及大規模題庫擴充，待第一階段穩定後再安排。
