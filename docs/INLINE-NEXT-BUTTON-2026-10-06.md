# 題目卡片內的下一題按鈕

「前往下一題」與答題解析移到題目卡片的文字欄，接在選項下方。桌面靠右排列，手機使用整欄寬度。

作答後若按鈕超出畫面，會捲動至按鈕；照片稍後載入時也會重新確認位置。按鈕保留上下捲動間距，避免緊貼畫面邊緣。

驗證：TypeScript、元件 ESLint、正式建置通過。本機長題目與雙子星塔題目在四種視窗尺寸共八種情境通過；桌面及手機各五題的實際流程，以及圖片失敗重試通過。詳細紀錄見同日 QA JSON。

正式網站桌面及手機各五題通過，確認按鈕位於卡片內、可見且能繼續作答。首次檢查曾遇到載入等待逾時，重跑通過。
